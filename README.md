# Fuel Tankering Optimizer

Single-file offline web app for multi-leg jet fuel tankering and FBO handling-fee optimization (G650ER / Falcon 2000LXS profiles, editable).

**Open the app:** https://adibiase.github.io/fuel-tankering-optimizer/

On iPhone: open the link in Safari, then Share > Add to Home Screen.

- Fuel in gallons and pounds (Jet-A density setting)
- Flight time estimated from ICAO codes (OurAirports data, offline)
- Optional forecast winds aloft (Open-Meteo; needs internet)
- Trip data is saved only in your browser (localStorage), never uploaded.

Estimates are for planning only and do not replace your flight-planning service.
